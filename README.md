# Tobiversity

A full-stack Learning Management System (LMS) designed to connect students, teachers, and admins in a simple, streamlined educational ecosystem. (Get it? Because my name is Tobi!)

**Created by Tobi Olu**

---

## Concept

**Tobiversity** bridges the gap between course content and classroom management. 

Instead of dealing with the hassle of multiple platforms, users can get a role-based experience built specifically for their needs:

> ### **Your Role Determines Your Dashboard**

The application automatically identifies who you are upon login, and models the interface to match your exact responsibilities, keeping your workspace focused.

---

## How It Works
1. You begin on a secure page where you register or log in to Tobiversity.  
<!-- I'll insert an image later -->

2. The application checks your assigned role (**Student**, **Teacher**, or **Admin**).

3. Each dashboard gives you unique actions based on that role:

   * **Students** can browse available courses, enroll, access a list of courses they are enrolled in.
   * **Teachers** can create and manage courses.
   * **Admins** can create and manage courses, as well as manage users.

4. Navigating through courses:

   * View course lists through a logic-driven, multi-page layout.
   * Read descriptions and track learning pathways instantly.

## Features

* **Role-Based Access Control**  
  Dynamically locks and unlocks features based on whether you are a student, teacher, or administrator.

* **RESTful Communication**  
  A swift Django Rest Framework backend securely serves structured JSON data directly to our reactive React frontend.

* **Responsive Design**  
  Adapts smoothly to mobile devices and desktop monitors alike using unified typography.  
  <!-- I'll insert an image later -->

* **Relational Integrity**  
  Built on a structured SQL database mapping users tightly to their enrolled courses.
